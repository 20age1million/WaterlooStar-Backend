# Project Areas — Backend API / Service

Use this file to populate the `index.md` layers table and assess phase scope
for backend API and service projects.

| Area | Examples |
|---|---|
| Domain / types | New identifiers, value objects, constrained types |
| Database schema | Tables, columns, indexes, constraints |
| Migrations | Up/down migration files |
| DB access layer | Queries, stored procedures, repository functions |
| Service layer | Business logic, orchestration, use cases |
| DTOs / contracts | Request/response shapes, mappers |
| API handlers | Route handlers, controllers |
| Routes | Route registration, middleware |
| OpenAPI / Swagger | Endpoint documentation, schema definitions |
| Auth / authorisation | Permission checks, token validation, RBAC |
| Configuration | Environment variables, feature flags, settings |
| Background workers | Queued jobs, scheduled tasks, event consumers |
| External integrations | Third-party API clients, webhooks |
| Tests | Unit, integration, contract, end-to-end |
| Deployment / infra | Container config, environment provisioning |
| Operational | Logging, metrics, alerting, tracing |
