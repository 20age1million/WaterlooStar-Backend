# Project Areas — Frontend / Web Application

Use this file to populate the `index.md` layers table and assess phase scope
for frontend and web application projects.

| Area | Examples |
|---|---|
| Routing | New pages, route guards, navigation changes |
| Components | New or modified UI components |
| State management | Store slices, reducers, context providers |
| API integration | Service calls, data fetching, cache strategy |
| Forms / validation | Input handling, schema validation |
| Auth / access control | Protected routes, permission-based rendering |
| Styling / theming | CSS, design tokens, component styles |
| i18n / l10n | Translation keys, locale handling |
| Configuration | Environment variables, feature flags |
| Tests | Unit, component, integration, visual regression |
| Build / bundling | Webpack, Vite, output targets |
| Deployment / CDN | Static hosting, cache invalidation |
| Accessibility | ARIA, keyboard nav, screen reader support |
| Analytics / tracking | Event firing, tag management |
