# Project Areas — Data Pipeline / ETL

Use this file to populate the `index.md` layers table and assess phase scope
for data pipeline and ETL projects.

| Area | Examples |
|---|---|
| Source connector | Input adapter, schema mapping |
| Transformation logic | Enrichment, normalisation, deduplication |
| Destination connector | Output adapter, upsert strategy |
| Orchestration | DAG definition, scheduling, dependency chain |
| Data contracts | Schema, format, validation rules |
| Error handling | Retry, quarantine, alerting |
| State / checkpointing | Progress tracking, idempotency |
| Configuration | Connection strings, batch sizes, schedules |
| Observability | Lineage, data quality metrics, alerting |
| Tests | Unit transforms, integration with source/dest |
| Deployment | Environment provisioning, pipeline registration |
